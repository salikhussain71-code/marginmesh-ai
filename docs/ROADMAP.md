# Roadmap

Only the first item is built. The rest is a plan, not a promise.

- [x] **v0.1** CSV/XLSX reconciliation, margin analysis, reports, synthetic data, CLI, local API
- [ ] **v0.2** Review workflow: persist human decisions (confirm / dismiss / correct) with audit log
- [ ] **v0.3** PDF invoice table extraction with side-by-side source view; manual correction UI
- [ ] **v0.4** Approved amendments, multi-currency with dated exchange rates, tax and freight terms
- [ ] **v0.5** PostgreSQL storage, accounts, per-company isolation
- [ ] **v0.6** Evidence-grounded explanations ("why did order X lose margin?") using retrieval
- [ ] Customer validation: interviews with exporters (see `CUSTOMER_DISCOVERY.md`) decide priority

A working demo is not a business. The product direction depends on whether finance teams confirm
this problem is frequent and costly enough to pay for.
